--- BlueStacks specific ---
Ports:
  BlueStacks 5: 127.0.0.1:5555, 5565, 5575, 5585
  MuMu 12: 127.0.0.1:7555, 16416
  Nox: 127.0.0.1:62001, 62025

Root:
  adb -s 127.0.0.1:5555 root -> restarting adbd as root
  adb -s 127.0.0.1:5555 shell id -> uid=0(root)
  adb -s 127.0.0.1:5555 shell setenforce 0
  adb -s 127.0.0.1:5555 shell getenforce -> Permissive

Package names:
  com.oxide.survivalisland
  com.oxide.survival
  com.catsbit.oxide

libil2cpp base:
  cat /proc/$(pidof com.oxide.survivalisland)/maps | grep libil2cpp
  First address is base, e.g., 0x7a3b200000
  VA = base + RVA
  Example: HitscanWeaponConfig damage getter RVA 0x... + base

For external cheat on BlueStacks:
  - Use process_vm_readv syscall 270/271
  - Need root + Permissive
  - Read /proc/pid/maps for base
  - Parse static fields for player list
